# Experience

I've been working in production engineering, technical support, and backend development since 2011. My career started in a small IT shop where I was writing SQL Server queries and building VB6 applications — a long way from the containerized environments I work with today.

The biggest shift happened when I joined Clearscope Solutions in 2018. I started as a developer, but over time I became the person the team called when something broke and no one could figure out why. That role wasn't planned — it grew out of repeatedly being the one who stayed on a problem until it was solved. Eventually I became the final escalation point for 18 applications, handling whatever landed on my desk: API failures, database corruption, third-party integrations breaking silently, deployment pipelines failing at 2 AM, protocol compatibility issues between legacy clients and modern infrastructure.

I didn't set out to be an escalation engineer. But looking back, every role I've had — from junior programmer to technical mentor to infrastructure modernization — prepared me for it.
